## ארכיטקטורת הקוד (JudoTrainer.jsx)

### קומפוננטות
| קומפוננטה | תפקיד |
|---|---|
| `useSound(soundType)` | צלילי interval timer (Flex Timer style) |
| `TimeWheel` / `TimePicker` | גלגלת זמן דקות:שניות |
| `Toggle` | כפתור on/off |
| `DrillForm` | טופס עריכת תרגיל |
| `EditorModal` | עורך מערך אימון (3 טאבים: תרגילים / חברי נבחרת / זוגות) |
| `WorkoutModal` | שמירה/טעינה/עדכון אימונים מ-Supabase |
| `AttendanceModal` | נוכחות לפי תאריך |
| `SplitPanel` | פאנל לבן/כחול — מי עובד עכשיו |
| `JudoTV` | קומפוננטת ראשית |

### מבנה תרגיל (drill object)
```js
{
  id, name, section, type,        // "group" | "partner" | "personal" | "rest"
  durationWork, durationRest,     // שניות
  rounds, pattern,                // "alternate" | "together"
  restTiming,                     // "none" | "after_each" | "after_round"
  activeColor,                    // "white" | "blue" | "both"
  autoNext, note
}
```

### מנוע שלבים (getDrillPhases)
כל תרגיל מתפרק לרצף שלבים: `{ phase, who, duration, label, round }`  
השעון עובר אוטומטית בין שלבים, עם התראה בכל מעבר.

## פיצ'רים קיימים

### תצוגה
- שעון ענק — **ירוק** כשרץ, **אדום** כשעצור
- פסי שלבים ויזואליים (לבן עובד → כחול עובד → מנוחה)
- פאנל לבן/כחול — הצד הפעיל גדול ובהיר, השני עמום וקטן
- כשניהם עובדים — שניהם מוארים
- הבא: שם התרגיל/שלב הבא

### שליטה
- ▶ הפעל / ⏸ עצור
- ← קודם / הבא →
- ↺ אפס שלב
- כפתורי זמן: **− דקה / − 30ש׳ / − 10ש׳ / + 10ש׳ / + 30ש׳ / + דקה**
- תיבת עריכה ידנית של השעון (MM:SS)
- מעבר אוטומטי — toggle גלובלי + הגדרה לכל תרגיל

### צלילים (Flex Timer style)
- t=3,2: ביפ קצר 1000Hz
- t=1: ביפ ארוך 1000Hz  
- סיום שלב: 3 ביפים עולים (880→880→1320Hz)
- אפשרויות: 🔔 ביפ / ⚡ באזר / 🔇 שקט

### עריכה
- גרירת תרגילים לשינוי סדר (drag & drop)
- שכפול תרגיל
- ספריית תרגילים (שמירה ב-Supabase)
- + תרגיל / + מנוחה

### חברי הנבחרת
- שמות בלבד (ללא כחול/לבן)
- שיוך לקבוצות + כפתור "קבוצה חדשה"
- סינון לפי קבוצה

### Supabase
- שמירת אימונים לפי תאריך
- עדכון אימון שמור (כפתור "עדכן")
- טעינת האימון האחרון בפתיחה
- נוכחות + היסטוריה

### תצוגה / נגישות
- כפתורי + / − לזום (50%–150%)
- פאנלים ניתנים לגרירה לשינוי רוחב (mouse + touch)
- PWA — ניתן להוסיף לדף הבית ולהריץ fullscreen
- תמיכה מלאה באייפד (touch events)

## 📱 שלט רחוק (טלויזיה + נייד)

המסך מוקרן בטלויזיה, והמאמן שולט ממנו מהנייד — בלי שכל הקבוצה תראה מה הוא עורך.

### חיבור
1. בטלויזיה לוחצים **📱 שלט רחוק** (בסרגל העליון, או ☰ ← 📱 שלט רחוק).
2. נפתח חלון עם **קוד חיבור** בן 4 תווים, קישור לממשק הנייד, וכפתור להעתקת
   קישור שכבר כולל את הקוד.
3. בנייד פותחים `‎/remote` ומקלידים את הקוד — או פותחים את הקישור המועתק
   (`‎/remote?code=XXXX`) ונכנסים ישר.
4. הקוד נשמר ב-localStorage בשני הצדדים — חיבור חוזר אוטומטי.

**הקוד לא מוצג על המסך המוקרן.** הוא קיים רק בתוך החלון הזה, והחלון נסגר מעצמו
2.5 שניות אחרי שהשלט מתחבר — כדי שאף אחד לא יקרא את הקוד מהמסך ויתחבר באמצע אימון.
הנקודה שליד הכפתור מראה אם יש שלט מחובר. **🔄 צור קוד חדש** מנתק מיידית כל שלט קיים.

### מה מיידי ומה נשמר בטיוטה
| פעולה | מתי המסך מתעדכן |
|---|---|
| ▶ התחל / המשך | **מיד** — ושולח קודם את כל הטיוטה |
| ⏸ עצור | **מיד** |
| ✓ עדכן טלויזיה | **מיד** — שולח את הטיוטה |
| שינוי זמנים, מעבר בין תרגילים | רק בשליחה (במצב פרטי) |
| עריכת מערך, תרגילים, הערות, הגדרות | רק בשליחה — תמיד |

בראש השלט יש מתג **🔒 מצב פרטי / 🔴 שידור ישיר**. בשידור ישיר כפתורי הזמן והניווט
משפיעים על המסך מיד; עריכת המערך נשארת בטיוטה בכל מקרה.

הפס הכתום בתחתית השלט מראה מה עדיין לא נשלח, עם כפתורי **בטל** ו-**✓ עדכן טלויזיה**.

### 📺 מצב הקרנה
מסתיר מהטלויזיה את כל כפתורי השליטה (זמנים, הפעל/עצור, זום, ערוך) ומשאיר תצוגה נקייה:
שעון, שלבים, לבן/כחול, רשימת התרגילים. נשלט מהנייד או דרך ☰ בטלויזיה.

### תשתית
- ערוץ **Supabase Realtime broadcast** — פאב/סאב בלבד, ללא טבלה חדשה וללא תלות npm נוספת.
  `app/lib/remoteBus.js` מדבר את פרוטוקול Phoenix ישירות מעל WebSocket, עם heartbeat
  כל 25 שניות והתחברות מחדש עם backoff.
- **הטלויזיה היא מקור האמת** ומריצה את השעון. השלט רק שולח פקודות ומשקף מצב,
  כך שהשעון על המסך אף פעם לא תלוי בחיבור.
- המסך משדר `tick` בכל שינייה ו-`full` כשהמערך משתנה; השלט מבקש `full` כשה-`rev` לא תואם.
- **צליל:** דפדפנים מתירים AudioContext רק מתוך נגיעה אמיתית. לכן, כל עוד לא נגעו במסך,
  מופיע שם באנר "🔊 לחצו כאן להפעלת הצלילים" — לחיצה אחת פותחת את הצלילים לכל האימון.

## הערות טכניות חשובות
- **AudioContext** חייב להיאתחל בתוך לחיצת משתמש (iOS) — נעשה ב-`initCtx()` בכפתור הפעל
- **`typeof window === "undefined"`** guard לכל קוד צד-לקוח
- **`'use client'`** חייב להיות שורה ראשונה בקובץ
- **`סה"כ`** בתוך JSX strings — להשתמש ב-`סה\"כ` עם escape
- הקובץ עבר babel parse validation לפני כל העלאה
- **טיימרים:** כל `setInterval`/`setTimeout` בקומפוננטה שמתרנדרת הרבה חייב לקרוא
  callbacks דרך ref ולהשאיר ב-deps רק פרימיטיביים יציבים. תלות בערך שמקבל זהות
  חדשה בכל רנדר (`advancePhase`, `phases`, `onClose`) בונה את הטיימר מחדש בכל
  רנדר — השעון רץ לאט, וטיימרים חד-פעמיים לא יורים בכלל.
- **איפוס שעון:** `drillClockSignature` קובע מתי מאפסים. שינוי שם/הערה של תרגיל לא
  מאפס את השעון; שינוי משכים/סבבים/תבנית כן. `clockOverrideRef` מאפשר לשלט לכפות
  מיקום שעון מדויק גם כשהאיפוס האוטומטי רץ באותו commit.
